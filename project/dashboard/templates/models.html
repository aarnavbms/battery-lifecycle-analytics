How to read this

Each model is trained on three cells. On the fourth, one input column at a time is shuffled, which breaks its link to health. If the error jumps, the model was relying on that signal. If nothing changes, the model ignores it.

Unlike the built-in importance of tree models (next row), this works for any model and is measured on data the model never saw.
