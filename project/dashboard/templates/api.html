REST API

Everything on this site is also available to other software through a versioned REST API. Reading is open. Changing anything needs a signed-in role, and the role decides what is allowed.

Getting started

Base address and sign-in

All paths start with /api/v1. Sign in to get a token, then send it with each request in the Authorization header. Tokens last 8 hours.


      
The machine-readable description is at /api/v1/openapi.json (OpenAPI 3.0). Errors always come back as {"error": {"code", "message"}}.
