Assess your own battery data

Give the system a file with one row per charge-discharge cycle. It works out each battery's health, forecasts the cycles it has left, grades it for a second life, and issues a signed Digital Battery Passport. Put several batteries in one file to get them ranked.

Assessing files and issuing passports is reserved for the Assessor role. You are viewing as a public visitor.

How to read the result

Health

Health is measured capacity divided by rated capacity, smoothed over nine cycles. If the file has charging signals for a trained cell type, the AI estimate is shown next to it so you can see how close the model is.

Cycles left

Two trend methods extend the health curve to 80% and 60%. The range between them is shown. These trend forecasts are rough: on the laboratory cells they were off by a quarter to more than the full life. Treat them as a guide.

Confidence

If the grade would change at the lower health bound, or between the two forecasts, the result is marked low confidence and a laboratory capacity test is recommended before the battery is redeployed.
